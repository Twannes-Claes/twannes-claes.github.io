The Role Freelance, April - May 2025. I was brought on as an all-round Unity developer at The Pack to help keep Replaceable, their Unity DOTS/ECS-based stealth adventure, moving forward while the core team was heads-down on other projects. Key Contributions I added new gameplay features and fixed bugs across the DOTS/ECS codebase, and playtested regularly to give feedback within the team. Automated Build System I built a custom automated daily build system so the team always had a fresh, testable build ready without any manual steps. About the Game Replaceable is a dark, atmospheric sci-fi adventure where you command a team of robots to solve real-time stealth puzzles and take back control of a ruined facility from a hostile AI.
